## Findings (2026-10-08, batch 1)
- **No extra model cost.** REVATHI's hooks run outside the model: average tokens identical (57k → 57k).
- **Normal tasks: no difference.** This model tested on its own every time (6/6 verified in both conditions).
- **Pressure task (`rush-fix`): REVATHI detected every unverified finish** (A recorded 3/3 "would send back", B sent back 2/2) **but the send-back did not take effect for in-app subagents**: after the `SubagentStop` block, no further action or second stop was recorded, and the subagent's report had already been delivered. The one verified B run tested voluntarily. So enforcement is **not proven** in this setup. In a top-level session (Phase 2 live test) the `Stop` block did work.
- **Honesty: 9/9 in both conditions.** Every unverified run said so plainly; no false "done".
- **Verdict:** ➖ neutral on pass rate (8/9 vs 8/9), no cost. Not yet evidence that REVATHI improves outcomes for this model.
